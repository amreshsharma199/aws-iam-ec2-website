👋 Hello, I am Amresh Sharma

This website was originally built to be hosted on Amazon EC2 (t2.micro) with Apache httpd. As part of Module 02, I learned IAM and EC2 deployment.

✅ IAM Concepts
Users, Groups, Roles, Policies, Least Privilege
✅ EC2 Launch
Amazon Linux 2023, t2.micro, Key Pair
✅ Security Group
Port 22 (My IP), Port 80 (0.0.0.0/0)
✅ Web Server
Apache httpd, systemctl, /var/www/html

Architecture

User Browser → Security Group (Port 80) → EC2 Instance → Apache → index.html

Security managed via IAM Role with Least Privilege.

Commands Used

sudo yum update -y
sudo yum install httpd -y
sudo systemctl start httpd
sudo systemctl enable httpd
sudo nano /var/www/html/index.html

Deliverables

  • GitHub Repo: This code
